## 招牌推荐
- 肉丝拌川：老杭州拌川，锅气足、酱香明显
- 片儿川：雪菜+鲜笋+肉片，汤鲜清爽
- 猪肝拌川：现炒嫩肝，不腥
- 大排面：大排软烂，汤头鲜
- 虾爆鳝面 / 黑鱼面：用料足，老客强推
- 加料：卤鸭、卤鸡爪、素鸡、千张包、馄饨

## 适合场景
大关小区/行知中学周边通勤饭；想吃得便宜有锅气的一人食；夜宵时段（16:00后）可吃。
